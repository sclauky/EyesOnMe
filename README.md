# EyesOnMe

### Commands to start the project

#### Windows:

```python -m venv .venv
./.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python desktop\main.py
```

#### Linux/macOs:

```
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python desktop/main.py
```
